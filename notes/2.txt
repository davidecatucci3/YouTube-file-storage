1. Documents (Office & Text)
.DOCX: Microsoft Word document (the standard for writing).

.PDF: Portable Document Format (best for "read-only" documents that shouldn't change).

.XLSX: Microsoft Excel spreadsheet (for data and numbers).

.PPTX: Microsoft PowerPoint presentation.

.TXT: Plain text file (no formatting, just text).

.CSV: Comma-Separated Values (used to export/import data between spreadsheets and databases).




2. Images (Photos & Graphics)
.JPG / .JPEG: The standard for photographs (small size, good quality).

.PNG: Best for web graphics, screenshots, and logos (supports transparent backgrounds).

.GIF: Used for simple animated images.

.WEBP: A newer format for the web that loads faster than JPG or PNG.

.SVG: Scalable Vector Graphics (used for icons and logos that need to be resized without losing quality).




3. Video
.MP4: The universal standard. Works on almost every phone, TV, and computer.

.MOV: High-quality video format often associated with Apple/iPhone.

.MKV: Popular for high-quality movies and streaming rips (often supports subtitles/multiple audio tracks).

.AVI: An older video format, less common now but still in use.




4. Audio
.MP3: The absolute standard for music and audio.

.WAV: Uncompressed, high-quality audio (used by professionals/recording).

.AAC: Slightly better quality than MP3, often used by Apple Music and YouTube.




5. Compressed (Archives)
.ZIP: The most common archive format; Windows and Mac can open these without extra software.

.RAR: A more efficient compression format (requires software like WinRAR).

.7Z: An open-source format known for extremely high compression (requires 7-Zip).




6. Web & Code (Technical)
.HTML: The structure of a webpage.

.CSS: The styling of a webpage (colors, fonts).

.JS: JavaScript (makes webpages interactive).

.PY: Python script.

.JSON: A format used for transmitting data between servers and web applications
